# Requisitos do QuantoTá?

- Comparar preços de produtos consumíveis entre mercados.
- Permitir cadastro de usuários.
- Permitir login simples.
- Permitir cadastro de produtos, mercados e preços.
- Permitir busca por nome do produto.
- Permitir montar lista de compras.
- Calcular valor estimado com base no menor preço encontrado.
